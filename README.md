# history-hjm 🐱

**哈基米牌正史野史构史**

> 历史不止一种写法，哈基米也有自己的史观（哈基米没有绿豆）。

## 📖 项目简介

`history-hjm` 

- **正史**：了解历史脉络，探寻人物与事件。
- **野史**：解锁趣闻轶事，看看历史的另一面。
- **构史**

## 🚀 本地运行

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

## 🐾 项目理念

正史有正史的考据，野史有野史。

至于哈基米牌构史嘛——

**历史可以严谨，野史必须够野，哈基米没有绿豆！**

---

*本项目主要用于学习、探索与展示中国历史相关内容。涉及历史传闻与野史时，将尽可能区分史实、推测与民间说法。*
