# history-hjm 🐱

**哈基米牌正史野史构史**

> 历史不止一种写法，哈基米也有自己的史观。

## 📖 项目简介

`history-hjm` 是一个以中国历史为主题的数字史馆项目，探索正史与野史的不同视角。

我们既看正史中的王朝更迭、人物功过，也关注野史里的奇闻轶事与另一种历史叙事。

以现代化的网页设计呈现历史，让历史更有趣，让构史更自由。

## ✨ 项目特色

- **正史**：了解历史脉络，探寻人物与事件。
- **野史**：解锁趣闻轶事，看看历史的另一面。
- **现代设计**：用更轻松、年轻的视觉体验呈现历史。
- **哈基米精神**：严肃地研究，不严肃地探索。

## 🛠️ 技术栈

- Vue 3
- TypeScript
- Vite
- Vue Router
- Pinia

## 🚀 本地运行

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

至于哈基米牌构史嘛——
